## Important note about image hosting

The current GitHub connection in this chat can update repository text files, but it does not provide a binary-image download/upload workflow from the external image hosts. Therefore, the HTML currently loads the above images from Wikimedia Commons rather than storing image copies inside this repository. The image links can be replaced with local paths (for example, images/conduit.jpg) after the image files are uploaded to the repository.

Where an image is adapted, attribution and the applicable ShareAlike licence conditions must be retained. Please check each Commons file page for the current licence and any updated attribution details before redistributing modified copies.
